1. 수집 및 접근하는 Google 사용자 데이터 (Data Accessed)

바탕화면 달력은 사용자가 본인의 Google 계정으로 로그인하여 권한을 승인한 경우에만 아래의 Google API 범위에 접근합니다.

  • https://www.googleapis.com/auth/calendar: 사용자의 Google Calendar 일정 조회, 추가, 수정 및 삭제
  • https://www.googleapis.com/auth/tasks: 사용자의 Google Tasks 할 일 목록 조회, 추가, 완료 체크 및 삭제

2. 데이터 사용 목적 및 저장 방식 (Data Usage & Local Storage)

접근한 Google Calendar 및 Google Tasks 데이터는 오직 사용자의 Windows PC 바탕화면 위젯 화면에 일정을 표시하고 양방향 동기화하는 목적으로만 사용됩니다. 본 애플리케이션은 별도의 외부 웹 서버나 데이터베이스를 운영하지 않으며, OAuth 인증 토큰(token.json)과 일정 캐시 파일은 오직 사용자 본인의 PC 로컬 폴더에만 저장됩니다.

3. 제3자 제공 및 공유 금지 (Data Sharing)

본 애플리케이션은 사용자의 Google 데이터를 제3자에게 판매, 전송, 대여하거나 광고 및 AI 학습 목적으로 절대 사용하지 않습니다.

4. 데이터 보관 및 삭제 (Data Retention & Deletion)

사용자는 언제든지 프로그램 내 구글 재인증/초기화 기능이나 로컬 데이터 폴더 삭제, 또는 Google 계정 권한 관리 페이지에서 앱 액세스 권한을 취소하여 모든 로컬 데이터를 즉시 삭제할 수 있습니다.

5. Google API Services User Data Policy Compliance (English)

바탕화면 달력 (MyDesktopCalendar)'s use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

All Google Calendar (.../auth/calendar) and Google Tasks (.../auth/tasks) data is processed and cached strictly on the user's local Windows computer. No user data is ever transmitted to, stored on, or shared with any external server or third party.
